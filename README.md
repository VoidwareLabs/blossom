# Blossom

**A space for ideas to grow.**

Creative studio by VoidwareLabs — Japanese UI gradients and a private ASCII art generator.

## Tools

- **[/gradients](/gradients)** — Traditional Japanese colours, curated sets, dither, air blur, image palette extract, multi-format export
- **[/ascii](/ascii)** — Image-to-ASCII with braille, dither, halftone, colour modes, presets, and local export

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
